# 高手怎么解题（情况4：解析作者的实操路径）

来源：2026 龙信杯解析全文 327 行，统计作者的操作动词与工具使用。

## 一、动词统计（这是方法论的指纹）

| 动词 | 次数 | 含义 |
|---|---|---|
| **查看** | 10 | 先打开看，不写脚本 |
| 发现 | 5 | 看出来的，不是算出来的 |
| 搜 | 4 | 关键词检索 |
| 解 | 4 | 解密/解包 |
| 看 | 3 | |
| 用 | 3 | 挑工具 |

| 过滤 | 2 | 缩小结果集 |

**结论**：`查看` × 10 压倒性第一。高手**先看再算**，不是先写脚本。

## 三、四条可直接抄的方法

### 3.1 「右键去原始目录」——GUI 工具给的是索引，答案在原始文件

> 题目：抖音最终打开的网址
> 作者：发现图片里面有可疑的二维码 → **右键去原始目录**，发现是抖音的下载数据 → 识别二维码

**方法**：取证平台（火眼/龙信）展示的是解析后的索引。**遇到平台没直接给出的字段，
去原始目录找那个文件本身**。平台不解析的东西，原始文件里往往是明文。

龙信杯 6 道题的答案都在明文库 `sy_chat_imPROD_SY.db` 里，
而火眼对这个 app 没有直接解析——同一逻辑。

### 3.2 「加到 DIE 里看」——判打包器不靠猜

> 题目：驿站客户端用什么模块打包
> 作者：**将快递 e 栈放到 die 里面**，PyInstaller

**方法**：`DIE`（Detect It Easy）一拖就知道是 PyInstaller / Nuitka / UPX / Go / Rust。
比 `strings` 找特征串快且准。

**本机等价物**：`D:\ForensicTools\Toolset\DetectItEasy\die.exe`（若有），
或 `strings | Select-String 'PYINSTALLER|MEI|nuitka'`。

### 3.3 「过滤 XX」——OCR 后必须过滤，不是人工翻

> 题目：AI 生成面单中单号尾号 502、寄件人尾号 5240
> 作者：批量 OCR 2000 张 → **过滤一下 5240**，昆明市

> 题目：手机号出现最多的后四位
> 作者：批量 OCR 1281 张 → Excel `=RIGHT(B2,4)` → `=INDEX(C2:C38, MODE(MATCH(...)))`

**方法**：OCR 全量跑完 → 表格工具批量提字段 → 过滤/统计。
**绝不抽检**。"最快的一个"「出现最多的」这类题必须全量。

### 3.4 「挂载」——加密容器第一步就是挂

> 作者：`挂载`（就两个字，说完就出结果了）

**方法**：VeraCrypt 拿到密码 → **直接挂成盘符** → 用资源管理器找。
不写解密脚本，不整卷导出。

龙信杯我在这上面浪费了 40 分钟（写了 105 GiB 全量解密脚本）。

## 四、作者的服务器解题路径（可复制的顺序）

```
1. 软件存放目录 → 发现"快递查询"、"ocr 识别软件" → 判定 server01 是网站服务器
2. /etc/systemd/ 搜 .service → 找到 dq-bootstrap.service
3. ExecStart → 拿到程序路径
4. 看文件时间线 → 选旧的那个（原始核心）
5. 同目录看清理脚本 → 看 stop_service 调用顺序
6. docker 的 mount 配置 → 找源码目录
7. 日志搜 sqlcipher → 找工具镜像标签
8. 日志搜 qenc → 找独立解密功能
9. 日志搜 dqcrypto → 找签名验证脚本
10. 跟一下原位置 → 发现 v31 版本
11. 搜 acquire_sig_text → 数第 6 个字段
```

**关键**：**每一步都是从上一个结果延伸出来的**，不是按题号做的。
这就是「源 × 题矩阵」的实战版——顺着一条线索走到底，沿途捡答案。

## 七、GUI 优先的具体清单

以下场景**先开 GUI，别写脚本**：

| 场景 | GUI 工具 | 路径 |
|---|---|---|
| 看二进制结构 | 010 Editor | 搜 `010Editor.exe` |
| 判壳/打包器 | DIE | 搜 `die.exe` |
| 手机/PC 综合取证 | 火眼 / 龙信 | `D:\ForensicTools\` |
| APK 反编译 | jadx | 搜 `jadx-gui` |
| 注册表浏览 | RegistryExplorer | `eztools\RegistryExplorer\` |
| ShellBags | ShellBagsExplorer | `eztools\ShellBagsExplorer\` |
| 中文 OCR | 苍穹 AI / umi-ocr / RapidOCR | 见工具清单 |
| CAN 总线 | SavvyCAN | `carlink\SavvyCAN\` |
| 容器挂载 | VeraCrypt GUI | `D:\ForensicTools\VeraCrypt.exe` |
| 服务器远程 | FinalShell / Xftp | 搜 `finalshell` |

**判据**：如果任务是「看一眼就知道」的，GUI 比脚本快 10 倍。
如果是「批量/统计/需要精确偏移」的，脚本才占优。
